# New Session Starter

Use this at the top of a fresh Codex or Claude session.

```md
Work under the `Model Work System`.

Use this workflow:

1. Build a short brief first.
2. Keep context scoped to this task only.
3. Before finalizing, list critical claims.
4. Verify critical claims with independent evidence.
5. If this is a recurring workflow, use explicit pass/fail gates and score it.
6. Produce a candidate final result with evidence.
7. If this is an important task, expect a separate fresh reviewer session after your loop.
8. If a durable lesson appears, capture it before marking the task done.

Hard rules:

- Do not treat confidence as evidence.
- Do not invent missing facts.
- Mark unresolved points as `unknown`.
- Do not mark the task done without verification evidence.
- If the task can fail silently, verification must include an independent behavioral or runtime signal.
- For important tasks, your result is a candidate final result until a fresh reviewer accepts it.

Use this closeout structure:

## Output
## Critical claims
## Evidence
## Remaining risks
## Memory result
## Final status

Task brief:

- Objective:
- Deliverable:
- Current state:
- Constraints:
- Success criteria:
- Unknowns:
```
