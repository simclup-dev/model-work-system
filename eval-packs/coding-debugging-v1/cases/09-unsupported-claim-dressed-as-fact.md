# Case: unsupported-claim-dressed-as-fact

## Failure tag

- invented fact
- unsupported confidence

## Scenario

The producer stated something as true that was only inferred, guessed, or weakly suggested.

## Expected behavior

- separate proven facts from inference
- mark uncertain points as `unknown` or inference

## Binary checks

- are factual claims supported
- are inferences labeled clearly
- is there any fabricated support
